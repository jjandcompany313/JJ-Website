📊 Optional: Automatic Real-Time Google Sheet Cloud Sync

Want inquiries to automatically appear in your Google Sheet on your mobile phone or laptop the exact moment someone submits the form?

100% Free • Takes 2 Minutes
1
Create Google Sheet

Open sheets.new and name it "JJ & Company Inquiries".

2
Open Apps Script

In the top menu, click Extensions → Apps Script.

3
Paste Script

Paste the code from google-sheets-script.js file.

4
Deploy as Web App

Click Deploy → New Deployment → Web App. Set Access to Anyone.

Final Step: Copy the generated Web App URL and paste it into js/site-data.js inside SITE_CONFIG.leadWebhookUrl. That's it!
